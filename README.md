# 公開金融統計の自動取得

日本銀行・財務省などの公的機関が公開している統計を、GitHub Actions で平日2回取得して `data/` に保存するだけのリポジトリです。
APIキー・認証情報・個人情報・独自の分析は一切含みません（取得するのは誰でもダウンロードできる公開データのみ）。

- `fetch.py` … 取得スクリプト（Python標準ライブラリのみ）
- `codes/boj.json` … 日本銀行 時系列統計データ検索サイトの系列コード
- `codes/extra.json` … 追加で取る公開ファイル（任意）
- `data/manifest.json` … 最終取得時刻とエラー

各統計の著作権・利用条件は各提供元に従います。
